## 🛡️ Cybersecurity Portfolio

Bienvenido a mi portafolio de ciberseguridad.

Este repositorio documenta mi proceso de aprendizaje práctico y el desarrollo de laboratorios enfocados en Blue Team, análisis SOC, respuesta a incidentes y seguridad informática. Cada laboratorio está diseñado para simular escenarios reales, documentando el procedimiento, las herramientas utilizadas, los hallazgos obtenidos y las lecciones aprendidas.

---

# 🎯 Objetivos

- Construir un laboratorio de ciberseguridad profesional.
- Documentar cada práctica de forma técnica y reproducible.
- Fortalecer habilidades para desempeñarme como Analista SOC.
- Automatizar tareas mediante Python y Bash.
- Aprender el uso de herramientas de análisis, monitoreo y respuesta a incidentes.
- Mantener un historial de versiones utilizando Git y GitHub.
